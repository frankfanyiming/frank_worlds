# 从参考到可进入的世界

先区分四种交付状态：设计提案、可编辑模型、引擎实机、网页发布。只报告已经取得证据的状态。

## 把参考变成约束

识别主参考、材质参考、比例参考与辅助资料。记录用户要求保留的识别元素，以及哪些尺寸只是制作推定。参考网站中的地图或动画截图不是测绘图。

选一个稳定尺度作为基准，例如角色身高 F。把门、桌、楼梯、镜头净空表达为相对尺度，再做小幅试调。“更宽敞”不自动意味着换装修、缩小角色或移除墙体。多人住宅分别保留风格档案。

先建立入口、楼层、功能分区和邻接关系，再细化家具。用普通玩家从街道进门、走楼梯、转弯、坐下和退出的路线约束布局；不要靠测试时瞬移代替可达性。

## 结构与表面分开处理

按轮廓、厘米级结构、毫米级表面三个尺度检查：
- 厚度、边缘、扶手、树皮大裂缝由几何承担。
- 木节、石板碎边、布料接缝按可见距离分配几何或贴图。
- 颗粒和纤维使用可导出的颜色、法线、粗糙度；节点预览效果须在最终 GLB 中复核。

家具导入前核对单位、正面、底部标高、整套还是单件。替换时同时处理旧件占位和碰撞；不要把新矮柜叠在旧书架上。

## 接入现有地形

检查建筑完整占地内的旧河床、围栏、道路和地面高度，而不只检查门中心。补有厚度的地基及连续的可行走连接。可见排水缝不应形成胶囊角色跨不过的物理断口。

阴影出现条带时，先隔离光照、法线、三角面绕序、重叠面和贴图。双面材质可能掩盖朝下的道路；不要先用增亮覆盖几何错误。

射线回答“有地面吗”，实际身体运动回答“走得过去吗”。两者分别记录。仅在有渲染窗口时等待绘制信号，无窗口物理检查独立完成和退出。

## 输出与复现

保留不可变输入和可重复构建脚本，约定一次统一坐标转换。输出模型、材质、碰撞/楼层入口清单和正常控制器路线证据。重新导入导出资产检查；不能以 Blender 图代替网页效果。

遇到反馈，记录：症状 → 定位证据 → 修正 → 未解决范围。只把本模型验证有效的参数留作案例，换模型重新测量。
