# XLands 制作方法 Skills

这五份技能提炼自三个世界的实际制作记录。下载包只含方法文本，不含模型、账号凭证或第三方服务权限。

| Skill | 适用问题 |
| --- | --- |
| [reference-to-playable-world](reference-to-playable-world/SKILL.md) | 将参考图转成布局一致、角色可进入的场景 |
| [repair-character-gait](repair-character-gait/SKILL.md) | 脚底滑动、手臂反折、蒙皮拉丝和引擎动画差异 |
| [budget-mobile-web-3d](budget-mobile-web-3d/SKILL.md) | 手机加载、内存、摩尔纹与持续绘制成本 |
| [persist-world-interactions](persist-world-interactions/SKILL.md) | 多步互动、同行、送礼与浏览器中途恢复 |
| [ship-resilient-world-home](ship-resilient-world-home/SKILL.md) | 不依赖 3D 的首页、故障联系入口与发布核验 |

按需复制单个技能目录到自己的技能目录，再告诉助手使用对应技能。先检查技能要求的工具是否可用；其中的项目测量数值是实例，不是通用预算。
