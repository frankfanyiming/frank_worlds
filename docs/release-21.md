# 第21版 · 朋友日常与界面、房间细化

## 本轮内容

毛利楼窗牌加粗、墙面浅蓝灰，夜间将咖啡暖灯与外部冷光分开。阿笠家按参考图整理环形厨房和双床，补充桌柜、座椅、茶具等结构；毛利、工藤、大雄邻居家具也补了门板、接头和软垫。蛙家连续蘑菇踏板、树桩桌杯碗与熊猫木作更新，两户重烘焙日/暮照明。原角色、街区与楼梯碰撞继续保留。

三个世界重做HUD和弹窗布局：单个面板互斥、可滚动内容、固定关闭按钮、手机44px触摸目标；相册有空态和照片卡片，朋友有固定入口。中文、繁体、英文、日文、韩文包含动态提示、对话、分数、地点及玩法文案。大雄翻译只作用于显示，不修改交互路由的语义。

熊猫朋友首版已在游戏实现：串门→一起做饭→送礼→步行出游→营地野餐→双人照片。料理按步骤保存，礼物留下实物；存档兼容旧三叶草和相册。浏览器同步状态镜像用于修复动作后立即刷新的IDB写入间隙，照片仍保存在浏览器文件系统。

## 验证边界

- 三世界桌面、390px竖屏、844px横屏实际Chrome渲染；原生两世界五语言菜单、相册和朋友面板，真实拍照入相册。
- 两原生世界三指同时移动、转向、跑步与释放；未以桌面触控模拟代替真机Safari性能结论。
- 阿笠等建筑41项、295段真实角色碰撞通路；熊猫完整同行4段、67.29米。
- 朋友纯状态22项、实机34项；即时刷新专项另见朋友证据目录。
- 大雄源文本290处、284翻译键×5语言及动态模板；TypeScript、原有加载/路线测试和生产构建。
- 两世界完整分块包、SHA-256、失败与损坏重试验证。

本文件记录源代码与本地引擎验证。网页发布版本、源提交和运行包SHA以公开 `release.json` 为准。编辑用原模型和完整中间截图保留在本地，仓库包含代表图与验证报告。
