# 三世界界面修订 / 本地验收

这是界面代码与本地浏览器证据，不是公开发布记录。青蛙早期UI候选使用当时的旧烘焙房间，场景截图只证明界面与引擎能同时运行，不能当最终家具或灯光验收。

- `bridge-translation.json`：Godot 4.7.2 直接运行词条与动态模板检查。
- `shell-frog/`：隔离网页壳的五语言、三尺寸布局检查，不含游戏模型。
- `runtime-frog/`：真实WebGL青蛙，中英文、1440×900 / 390×844 / 844×390，HUD、单菜单、相册空态。
- `runtime-frog-multilingual/`：真实WebGL繁中、日、韩同三尺寸，并打开朋友卡。韩语卡验证没有汉字回退。
- `runtime-frog-photos/`：真实拍照后进入非空相册，图像已解码显示；英语朋友卡没有中文回退。
- `doraemon/`：真实Three.js场景，口袋和设置面板；触屏尺寸、每按钮44px、关闭按钮在滚到底后仍可触达，底层HUD隐藏。
- `runtime-conan/`：柯南 UI 候选包，五语言 × 三尺寸，菜单滚动到底并点击实际地点；不是最后夜景色彩包。
- `final-conan/`：最终模型与灯光导出后的本地 8791 预览，五语言 × 三尺寸共30项通过，0运行错误。检查单层菜单、实际 CSS 视口匹配、44px点击目标、底层HUD隐藏、滚到底仍可关闭、末项点击后真实位置对应。
- `final-frog/`：最终房间与朋友模块导出的本地8791预览，五语言 × 三尺寸，菜单/空相册/朋友卡/旧行囊，行囊切换朋友日记后关闭；另实际拍照并显示带地点的照片，共35项通过，0运行错误。截图和报告属于独立存档提交修正前的导出，界面代码相同；它们只验收界面，不作为最终Web存档持久化证明。

`runtime-frog/initial-resize-regression.json`保留了最初的不足检查：它虽报旧断言通过，但390px目标实际得到1440px CSS视口，所以不应视为通过。新的`report.json`加入设备尺寸一致性断言并修正画布尺寸后通过。

复验时设置 `NATIVE_BASE`、`WORLDS_BASE` 指向候选服务器；`UI_LANGUAGES` 可选5语言，`UI_EVIDENCE` 指定单独输出目录。全部是桌面Chrome真实渲染+触控模拟，不是真手机验收。

界面实施冻结后，仅存档桥接修正重新导出的包由朋友机制与主任务另验，不重复把同一界面截图当作新增通过。相册实拍图已人工核对完整比例、英语单数 `1 photo` 和地点标题；中文手机HUD、英语朋友卡及柯南横屏滚到底的关闭入口也已看图复核。
