# 熊猫茶屋：第二轮真实模型细节

本目录使用 `worlds/frog/blender/panda-home.blend` 的实际几何，以及独立导入的 Tripo 熊猫渲染。不是概念图，也不能替代 Godot 实机验收。用户参考用于石、木、草编、布料和生活物件的制作方向；房间尺寸、右侧楼梯、家具占地与既有行走路线保持不变。

- `panda-room-main-blender.png`、`panda-room-side-blender.png`、`panda-room-loft-blender.png`：同一房屋全景、侧面与夹层。
- `panda-tea-detail-blender.png`：真实茶桌、竹节与木榫、下垂桌布与刺绣、陶壶、干花、编织地毯与圆坐垫。
- `panda-stone-detail-blender.png`：连续岩壁、浅层片、矿物表面及圆窗花格。
- `asset-manifest.json`：本轮房屋运行模型、源文件与渲染的大小、摘要及 GLB 结构核查。

环境与家具均由 Blender 几何制作。唯一新增的生成图片是墙上卷轴的水墨画，位于真实卷轴模型表面；原始 PNG 与提示词保存在 `worlds/frog/blender/panda-ink-landscape.png` 和同名前缀的 `-prompt.txt`。运行纹理使用 JPEG 压缩副本，源画保留不变。窗后景是低对比的天空与树色纹理，不是房屋背景图。

本轮有效修正与踩坑：

1. 墙面不能把完整 Voronoi 多边形逐块描出深缝。第一次细节导出像砌石墙板，已弃用。现在保留连续围护，以浅起伏基底、少量边缘埋入基底的宽岩面、局部窄裂隙形成天然岩体。宽斜面由真实几何承担，细颗粒由法线纹理承担。
2. 岩面深度过大也会像粘在墙上的石块。本轮把浅岩面控制在约 4.5–10.5 cm，并把大部分外缘埋入原墙。需要同时看全景与近景，不能只看噪声局部。
3. 不规则地面若缝宽、材质明暗差大，仍会形成棋盘。改为混合尺寸的实际厚石板、较窄接缝、小倒角和局部碎边，收窄相邻材质色差。
4. 木纹须顺构件长轴。统一平面投射曾把长板变成横向条纹；当前按构件最长轴选择 UV 方向，并降低周期纹反差。
5. 草编使用交叉绳股和盘绕曲线，转换成真实网格后补物理尺度 UV；表面用无损法线纹理补细纤维。不能仅以一个有条纹的光滑球代替坐垫。
6. 所有表面细节都连接到 glTF 可导出的颜色、法线与粗糙度。数据贴图使用 Non-Color，颜色采用已经过色块与 GLB 往返实验确认的线性/sRGB 转换。颜色可有损压缩，法线与粗糙度保持 PNG；相同材料类别复用数据纹理控制网页体积。
7. 窗格与后景分离。窗后景运行节点名为 `PandaWindowBackground`，引擎关闭其投射阴影；真实花格仍投影。灯光位置由 `panda-home.json` 的 `windows` 与 `lamps` 提供。

本轮未改角色文件、角色动作、引擎控制器或发布。角色后续迭代及引擎灯光由对应流程验证；此处的熊猫姿态以本次渲染导入的角色文件为准。
