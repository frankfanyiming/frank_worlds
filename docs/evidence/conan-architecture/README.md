# 柯南建筑还原证据

本目录记录 2026-09-12 的建筑模型与几何检查。发布状态由主项目的实际网页验收与发布清单决定；本目录存在不代表已经上线。

## 源与运行合同

- 来源、脚本、源模型和 10 个运行文件的 SHA256：[来源清单](../../conan-architecture-source.json)。
- 原生模型 317,184 三角、35 个合并网格；可编辑阿笠源保留 2,549 个对象：[构建报告](agasa-build-report.json)。
- 原生与网页衍生、贴图降采样和仅视觉简化：[运行报告](architecture-runtime-report.json)。
- 原街区的局部删除与地形孔：[原生补丁](source-street-patch-report.json)、[网页补丁](web-project-street-patch-report.json)。它们保留未替换地标、节点变换和嵌入纹理字节，未更改普通车资产。
- [几何对照](geometry-contract.json)：22 组碰撞网格的三角坐标在 1e-5 米精度相同；两版本各 60 条孔内射线畅通、12 条孔外射线有地面，旧独立伊吕波楼完整包围范围内无剩余三角。

## 图像的实际含义

`agasa/` 的 9 张图是最终建模源在 Blender 内的真实渲染，包含双圆弧外观、前门、后塔与车库、厨房、双床、地下研究区、仪器、楼梯与屋内车库通道。保留墙体和顶棚，局部遮挡也是真实模型的一部分。

`mouri/` 的 3 张图将原毛利楼与新的连排商铺一起渲染；原毛利楼属于独立模型，不重复装进新街区 GLB。

`shared-scene/` 是同一个 Blender 街区场景的邻居关系证据，包括毛利楼连续街面、阿笠与工藤邻居关系、后塔与车库。该场景只读实际 GLB，不用插图地图或图片背景伪装几何。

引擎室内实际截图在工作区 `outputs/柯南与移动端升级/柯南实机空间/`，由主任务检查。Blender 渲染的照明和 Godot Compatibility 不同，不能拿前者代替后者。

## 真角色路线验收

`route-pass-*` 是实际 CharacterBody 移动记录。前几轮保留失败：桥端 26cm 缝、上行头顶碰平台，以及左侧桥横穿同圈上升段。它们不是最终通过报告。

当前冻结版采用每圈起末各 30° 同高平台、其余 300° 连续上升，正前桥连接。[最终 pass06](route-pass-06/physical-routes.json) 已通过 41 组检查、291 段实际行走，零失败；覆盖连续街面、入口、厨房工作内环、地下上下与研究区往返、环廊整圈双向、车库往返及下楼返回门外。验收绑定报告内 GLB/JSON/控制器 SHA，不能自动沿用到后续几何或控制器改动。

pass05 剩余问题是椭圆采样路线的弦线穿过现有结构柱；最终只给左右结构柱加了外侧绕行点，未改 GLB。孔的几何射线和碰撞导出一致性不替代这些真走检查。

重建步骤、参考来源、坐标和实际踩坑见 [制作方法](../../conan-architecture-workflow.md)。
