此处记录源码与构建检查，未做新的浏览器或真实手机帧率测试。构建及公开部署结果在完成后补录。

首次产物校验发现 Vite 8 / Rolldown 的压缩会删除普通 banner，即使 `/*!` 注释也不保留。改为压缩后的 `postBanner`，并将提交标识纳入 chunk hash；文件清单在生成 HTML 后记录。不能以“构建通过”替代逐文件来源标识检查。
