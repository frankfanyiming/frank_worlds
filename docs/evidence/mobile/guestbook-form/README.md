# 来访本窄屏表单修正

世界和首页顶部已通过手机视口检查后，整页截图发现390px时表单右侧裁切。根因是grid默认min-content撑宽，外层overflow隐藏掩盖了越界。

只修改xlands.css：表单与label可收窄，grid使用minmax(0,…)；手机竖屏的昵称和邮箱改为单列。360×640、390×844、844×390逐个输入框、选择框、复选框和按钮的边界验证通过。输入区域/主要操作目标至少44px，字号16px。

真实触摸聚焦和输入均通过；提交事件在客户端捕获并阻止业务处理，mutatingRequests=0，没有向公开来访本发送任何留言或邮箱。此测试证明布局和触摸命中，不证明后端留言服务可用。浏览器为桌面Chrome触摸模拟，非实体手机。
