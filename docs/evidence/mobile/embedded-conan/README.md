## 保留修复前证据

本目录根部的 report.json 和 01–10 截图属于修复前：Godot PopupMenu 能打开，但手指拖动转了背景相机，触摸列表行不能选中，摇杆覆盖后面的条目；日文时内部菜单仍是中文。05/07 中的滚轮与点击只是定位问题的鼠标诊断，不能算触摸通过。

修复后证据全部放在 `final/`。手机端由 DOM 滚动面板显示原 Godot 条目，点选仍回调原 ID，保留目的地位置数据；面板打开时释放移动并屏蔽触控/视角。最终两次厨房触摸选择与一次行囊开关均在新导出包执行，没有修改生产代码或在测试中直接调用传送接口。

可复用经验：长菜单必须实际手指滚动、点选，并核对场景变化；语言切换后再点一次相同目的地。原生 PopupMenu 的内部节点不应依赖普通子节点遍历翻译。模拟测试工具经 PTY 输入长单行时还可能触发终端行长限制；本轮将操作拆成短句后恢复，这不是游戏回调失败。
