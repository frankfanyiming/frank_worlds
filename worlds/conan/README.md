# 侦探事务所 / 米花町

采用 2026-09-10 已确认的 Blender 车流版本。人物和博士甲壳虫保留 Tripo；建筑、普通车流、街道物件来自 Blender。6 辆普通车流使用三种 Blender 车型。

`source` 保留原桌面项目脚本；`web-project` 是网页衍生版。保留人物绑定与动作，主角 4K 贴图；场景经 Blender 简化，网页导入时限制环境纹理尺寸。原始模型另外归档，不被网页优化覆盖。

完整资产通过根目录 `tools/fetch-native-assets.py` 下载，并核验 SHA-256 后解压。资产包链接见 `asset-manifest.json`。大型资产按仓库约定放在 GitHub Releases；源代码与版本清单保存在 Git。
